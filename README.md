# Mi Fitness mod

Неофициальная модификация приложения **Mi Fitness** (Xiaomi Wear, `com.xiaomi.wearable`) для браслетов и часов Xiaomi.
Здесь лежат не готовое приложение, а **патчи и скрипт сборки**: APK собирается у себя из оригинального пакета
приложения. Готовые сборки — в разделе Releases (если они там есть).

Проект не связан с Xiaomi. Используйте на свой риск.

## Важно

- Разделы **«Профиль», «Тренировка» и «Здоровье» (с «Сном») берутся из APK и не обновляются с сервера Xiaomi** — иначе скрытые модом
  элементы вернутся. Новые функции этих разделов появятся только с новой сборкой мода.
- Переключатель **«Не учитывать шаги телефона» работает только на телефонах Xiaomi** (MIUI/HyperOS). На других
  телефонах Mi Fitness шаги телефона и так не берёт, и переключатель ничего не меняет.
- Если в исходном пакете приложения нет русского языка, сборка берёт перевод из предыдущей версии (`RU_FROM`):
  строки, появившиеся в новой версии, остаются на английском.

## Установка готовой сборки

1. Скачайте APK из Releases и сверьте SHA-256 с указанным в описании релиза.
2. Если стоит официальное Mi Fitness, его нужно удалить: подпись мода другая, поверх оригинала он не встанет.
   Данные приложения на телефоне при этом пропадут (данные в аккаунте Xiaomi остаются).
3. Установите APK, войдите в аккаунт, привяжите браслет заново.
4. Следующие сборки мода ставятся поверх, данные сохраняются.

## Сборка у себя

Нужны: bash (Git Bash на Windows), perl, JDK 21, Node.js (проверка JS-бандлов), Android SDK build-tools, `tools/apktool.jar`, `tools/APKEditor.jar`,
`tools/junit-console.jar` (в репозиторий не входят), оригинальный пакет Mi Fitness (`.apks`, `.apkm` или `.xapk`) в `target/`.

```bash
./build.sh --tests-only            # только компиляция Java-частей и тесты
BAND_BUILD=1 RU_FROM=3.59.2i ./build.sh   # APK out/MiFitness.<версия>-band-1.apk и out/release-notes.md
FIRMWARE_INSTALL=0 ./build.sh      # без экрана «Прошивки»
scripts/make-repo.sh               # собрать эту папку и проверить, что в ней нет ключей, логов и APK
```

### Выпуск сборки

1. Собрать с новым номером: `BAND_BUILD=<N> RU_FROM=3.59.2i ./build.sh` — тесты, проверки байткода, подписи, разрешений.
2. Поставить на телефон (`scripts/phone-verify.sh install`), пройти проверку из `release/status.md`, записать результат туда.
3. Обновить `out/release-notes.md` (раздел «Изменения относительно прошлой сборки») и `release/status.md`.
4. `scripts/make-repo.sh`, коммит `v<версия>-band-<N>` в `main`, тег `v<версия>-band-<N>` на этот коммит, `git push` ветки и тега.
5. `scripts/publish-release.sh <N>` — только проверки и сводка: тег на GitHub = текущий `main`, SHA-256 и подпись APK
   (сертификат `1da8b9cb…`), `check-repo.sh`. Сводку (тег, название, файл, SHA-256, изменения) показать владельцу.
6. После его «да»: `scripts/publish-release.sh <N> --yes` — релиз «Mi Fitness <версия> band-<N>» с описанием из
   `out/release-notes.md` и APK, отметка latest. Скрипт сам проверяет через `api.github.com/…/releases/latest`, что
   latest — новый релиз и файл скачивается с тем же SHA-256. Нужен вход в GitHub CLI (`gh auth login`), токены в файлы
   и команды не вписываются.

Ключ подписи создаётся при первой сборке в `keys/` и **не публикуется**. Каждая следующая сборка должна подписываться
тем же ключом, иначе установка поверх невозможна.

Патчи привязаны к конкретной версии приложения: хуки (`hooks.txt`) переносятся сами, но обфусцированные имена классов
и разметка меняются от версии к версии — это ищется заново, см. `patches/README.md`.

## Риски

- Это изменённое приложение с другой подписью. Xiaomi его не проверяла; обновления из магазина на него не ставятся.
- Неверная прошивка может повредить браслет. Экран «Прошивки» проверяет модель, ветку, версию и заряд, но
  ответственность за файл на вас.
- Переход с китайской прошивки на глобальную проверен на одном браслете (NFC, q66tc, и то вручную через Notify, не через мод).
  Возврат на китайскую через мод невозможен. После перехода штатное обновление для браслета заблокировано, обновлять — только файлом.
- «Профиль», «Тренировка» и «Здоровье» не обновляются с сервера Xiaomi (см. «Важно»).
- Журналы могут содержать личные данные (названия приложений, тексты уведомлений, имена). Мод скрывает токены, идентификаторы, MAC, e-mail и телефоны, но не всё: отправляйте журнал только в личные сообщения.
- Сборка из пакета без русского сплита без `RU_FROM` будет на английском; с `RU_FROM` новые строки остаются английскими.
