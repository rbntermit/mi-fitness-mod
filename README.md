# Mi Fitness mod

Неофициальная модификация приложения **Mi Fitness** (Xiaomi Wear, `com.xiaomi.wearable`) для браслетов и часов Xiaomi.
Здесь лежат не готовое приложение, а **патчи и скрипт сборки**: APK собирается у себя из оригинального пакета
приложения. Готовые сборки — в разделе Releases (если они там есть).

Проект не связан с Xiaomi. Используйте на свой риск.

## Важно

- Разделы **«Профиль», «Тренировка» и «Здоровье» (с «Сном») берутся из APK и не обновляются с сервера Xiaomi** — иначе скрытые модом
  элементы вернутся. Новые функции этих разделов появятся только с новой сборкой мода.
- Переключатель **«Не учитывать шаги телефона» работает только на телефонах Xiaomi** (MIUI/HyperOS). На других
  телефонах Mi Fitness шаги телефона и так не берёт, и переключатель ничего не меняет.

## Установка готовой сборки

1. Скачайте APK из Releases и сверьте SHA-256 с указанным в описании релиза.
2. Если стоит официальное Mi Fitness, его нужно удалить: подпись мода другая, поверх оригинала он не встанет.
   Данные приложения на телефоне при этом пропадут (данные в аккаунте Xiaomi остаются).
3. Установите APK, войдите в аккаунт, привяжите браслет заново.
4. Следующие сборки мода ставятся поверх, данные сохраняются.

## Риски

- Это изменённое приложение с другой подписью. Xiaomi его не проверяла; обновления из магазина на него не ставятся.
- Неверная прошивка может повредить браслет. Экран «Прошивки» проверяет модель, ветку, версию и заряд, но
  ответственность за файл на вас.
- Переход Smart Band 11 с китайской прошивки на глобальную проверен многими пользователями.
  Возврат на китайскую через мод невозможен. После перехода штатное обновление для браслета заблокировано, обновлять — только файлом.
- «Профиль», «Тренировка» и «Здоровье» не обновляются с сервера Xiaomi (см. «Важно»).
- Журналы могут содержать личные данные (названия приложений, тексты уведомлений, имена). Мод скрывает токены, идентификаторы, MAC, e-mail и телефоны, но не всё: отправляйте журнал только в личные сообщения.

## Band-5

Полный APKS 3.60.0i содержит штатный русский, обе архитектуры (arm64-v8a, armeabi-v7a) и плотности экрана. Перенос перевода из 3.59.2i не нужен. Переключатель простой синхронизации DND теперь читается одинаково процессами приложения. Для Wear OS (включая Watch 5 o61w) отключена модификация запросов циферблатов. Исправление связи с Watch 5 пока не подтверждено устройством.

## Обновление мода из приложения (с band-6)

Устройство → Ещё → Обновление мода. По кнопке загружается APK из релиза этого репозитория. Проверяются SHA-256 GitHub, размер, номер сборки в APK, имя пакета, версия и совпадение сертификата с установленным приложением. Для запуска установщика добавлено одно разрешение REQUEST_INSTALL_PACKAGES; установку всегда подтверждает пользователь в Android. Метаданные проверяются не чаще раза в сутки автоматически и вручную по кнопке; автоматической загрузки нет. Токены GitHub и данные устройства/аккаунта не отправляются.

Band-6 нужно впервые установить обычным способом: старые версии открывают страницу релиза. Внутреннее обновление рассчитано на последующие сборки с подписанным маркером номера сборки. Если у релиза нет подходящего APK/SHA-256, остаётся переход на страницу релиза. OTA прошивки устройства и экран «Прошивки» работают отдельно.

## Band-7

Выбор службы подключения возвращён к поведению band-4 после отзывов о REDMI Watch 6 и Watch S5. Требуется проверка на этих часах. Для NFC-ключей переведены 89 строк и добавлено обновление списка при возврате в Xiaomi Pay; проверки SDK и создание карт не изменены. Диктофон на глобальной прошивке не включён: наличие его ресурсов подтверждено, безопасный способ включения пока не найден. Простая синхронизация DND на Band 10 по отзыву не работает и на band-6; в band-7 её отправка не менялась. Подробности: RESEARCH_BAND7.md.

Band-7: ожидание NFC-списка перестаёт блокировать экран через 30 секунд; исходная загрузка SDK может завершиться позже. DND на SB 10 и восстановление связи RW 6/S5 пока не подтверждены. Локальный эксперимент RECORDER_EXPERIMENT=1 не входит в обычный APK; на проверенной глобальной прошивке диктофон не появился даже после перезагрузки.

## Band-8

Простой DND для устройств без поддержки правил переведён на штатную команду старого протокола; добавлены подтверждения/ошибки транспорта и защита от старых ответов. 349 локальных тестов, подпись, выравнивание и проверка байткода пройдены. На SB 11 запуск и подключение проверены; DND на SB 10 требует проверки владельцем. APK и изменения — в релизе v3.60.0i-band-8. Штатный диктофон на глобальной прошивке не включён; отдельный RPK-пробник исследуется с разрешения владельца. Подробности: RESEARCH_BAND8.md.
