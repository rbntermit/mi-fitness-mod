# Возможности патчей Mi Fitness Mod

| Патч | Назначение |
|---|---|
| 00-core | Основные функции мода и дополнительные пункты меню |
| 01-watchface-install | Установка циферблатов из файла и отображение локальных циферблатов |
| 02-rpk-third-party-apps | Установка и управление RPK на совместимых устройствах |
| 03-hyperos3-signature | Совместимость подключения на HyperOS |
| 04-notifications-dedup | Уменьшение повторов уведомлений |
| 05-dnd-sync | Синхронизация режима «Не беспокоить», в том числе отдельный простой режим |
| 06-china-region | Изменения региональных ограничений приложения |
| 07-hide-health-summary | Переключатель скрытия сводки здоровья |
| 08-manual-weather-location | Ручная локация погоды |
| 09-app-language | Выбор языка браслета |
| 10-android-compat | Совместимость установки файлов с версиями Android |
| 11-no-secret-logs | Секрет сессии не пишется в журнал |
| 12-firmware-install | Установка прошивки из файла с проверками |
| 13-disable-firebase-stats | Отключение статистики Firebase |
| 14-fix-copyfile | Исправления копирования файлов |
| 16-guard-stock-ota | Защита от неподходящего штатного OTA |
| 17-skip-guide-webpage | Пропуск завершающей веб-страницы руководства |
| 18-github-update-check | Проверка и загрузка обновлений мода с подтверждением установки Android |
| 19-phone-steps-off | Отключение учёта шагов телефона на Xiaomi |
| 20-declutter | Скрытие рекламы и лишних элементов, исправления подписей интерфейса |
| 21-log-export | Сохранение и отправка журналов, маскировка чувствительных данных |
| 22-nfc-door-cards | Русские строки NFC-ключей и обновление списка карт |
| 23-recorder-experiment | Исследовательский компонент; в обычный APK не включается |
| 24-face-sync-fallback | Повтор получения циферблатов при определённой ошибке чтения |
| 25-miui-todo-access | Защита от отправки пустого списка задач при отсутствии доступа к MIUI |
| 26-notification-text | Уведомления без emoji, верхний регистр и пауза пересылки при «Не беспокоить» на телефоне. Все три опции по умолчанию выключены |

Наличие патча не гарантирует поддержку функции каждой моделью устройства. Текущие ограничения указаны в основном README и описании релиза.
