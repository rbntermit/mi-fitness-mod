# band-6: обновление APK и существующее OTA

Обновление мода — отдельный путь от OTA устройств. Устройство → Ещё → Обновление мода.

В штатной 3.60 есть com.mi.health.appupgrade (обновление приложения) и Research AppDownloader.
Найденный Research AppDownloader.installApk — private ACTION_VIEW + FileProvider + тип APK; его загрузки привязаны к Xiaomi Research/магазину.
Повторно используется уже объявленный FileProvider Mi Fitness и тот же системный механизм установки. Исходники OTA прошивки (патчи 12 и 16) не изменены.

Загрузка начинается только по кнопке пользователя. Подходящий asset — ровно один APK с точным именем/тегом, uploaded, известными размером (до 512 МБ) и SHA-256 GitHub.
Начальный адрес — только releases/download этого репозитория; перенаправления вручную проверяются: HTTPS, без userinfo/фрагмента/нестандартного порта, только github.com (исходный адрес), release-assets.githubusercontent.com и objects.githubusercontent.com.
Ни GitHub-токенов, ни cookies, ни данных устройства/аккаунта в загрузке нет. Тайм-ауты, предел размера, предел числа перенаправлений; прерванный файл удаляется. Частичные и старые APK в собственной папке очищаются через сутки.

Перед установкой повторно проверяются размер/SHA-256, подписанный маркер assets/markus-mod-build.txt (точный тег), пакет com.xiaomi.wearable, versionName, отсутствие понижения versionCode и совпадение сертификата APK с установленным приложением. Android выполняет системную проверку и запрашивает подтверждение установки.

REQUEST_INSTALL_PACKAGES — единственное новое разрешение, отдельно подтверждено пользователем. Само разрешение не даёт тихой установки: Android 8+ требует разрешить источник и затем подтвердить установку. В существующие разрешения/OTA-guard другие изменения не внесены.

Сначала band-6 ставится обычным способом, поскольку опубликованные band-1…5 умеют открывать только браузер. Номер сборки и маркер включаются в будущие APK скриптом сборки. Старые APK без маркера через новый установщик не ставятся.

Проверки: синтетические APK (хеш, размер, marker), имитация HTTPS-передачи/перенаправлений/отмены/обрывов, разбор метаданных настоящего публичного релиза band-5. Переход к системному установщику и установка на физическом телефоне пока не выполнены. Отчёт сборки — в out/release-notes.md.
